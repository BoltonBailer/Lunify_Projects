# Marcos Luna — AI Engineer Portfolio

A clean, Apple-inspired static portfolio designed for GitHub Pages.

## Quick setup

1. Create a GitHub repository named `BoltonBailer.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Replace the placeholder images with your own screenshots:
   - `images/osrs-predictor.png`
   - `images/ore-detection.png`
   - `images/price-tracker.png`
4. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
5. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.

Your site should then be available at `https://boltonbailer.github.io/`.
